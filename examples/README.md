# ESP32AutoTask examples

> 日本語版: [README.ja.md](README.ja.md)

## Workflow and individual READMEs

Start with the [example workflow](../docs/GUIDE_EXAMPLES.md), then choose the relevant sketch.

A useful starting point is [01_basic](01_basic/README.md). Check its required hardware and choose another entry below if it does not match your setup.

| Example | Learn |
|---|---|
| [01_basic](01_basic/README.md) | Start a named hook with the default task configuration |
| [02_stack_override](02_stack_override/README.md) | Override worker stack storage for a hook workload |
| [03_custom_config](03_custom_config/README.md) | Change selected hook periods and priorities |
| [04_full_config](04_full_config/README.md) | Construct an explicit per-hook task configuration |
| [05_gpio_blink](05_gpio_blink/README.md) | Toggle an LED from a periodic hook task |

# ESP32AutoTask サンプル

> English: [README.md](README.md)

## 実行ガイドと個別README

最初に[サンプル入門ガイド](../docs/GUIDE_EXAMPLES.ja.md)を読み、目的に合う例へ進んでください。

最初の候補は[01_basic](01_basic/README.ja.md)です。必要な機器を確認し、対象が異なる場合は下の一覧から選び直してください。

| 例 | 学ぶこと |
|---|---|
| [01_basic](01_basic/README.ja.md) | 既定設定で名前付きフックを開始する |
| [02_stack_override](02_stack_override/README.ja.md) | フックの処理に合わせてスタック容量を指定する |
| [03_custom_config](03_custom_config/README.ja.md) | 一部のフックの周期と優先度を変更する |
| [04_full_config](04_full_config/README.ja.md) | 各フックの設定を明示してタスクを開始する |
| [05_gpio_blink](05_gpio_blink/README.ja.md) | 周期フックでLED出力を切り替える |
